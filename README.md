# TwinVision Frontend

Este é o frontend do projeto TwinVision, desenvolvido com React Native e Expo.

## Requisitos

- Node.js (recomendado: 18+)
- Expo CLI (instale com `npm install -g expo-cli`)
- Dispositivo com Expo Go instalado (Android ou iOS)
- Acesso à mesma rede Wi-Fi do backend

## Instalação

1. Clone o repositório e entre na pasta do projeto:
   ```bash
   git clone https://github.com/seu-usuario/digitaltwin-challenge-visualizer.git
   cd digitaltwin-challenge-visualizer
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

## Executando

1. Inicie o projeto com Expo:
   ```bash
   npm start
   ```

2. Escaneie o QR Code com o aplicativo Expo Go em seu celular.

> Certifique-se de que o backend esteja rodando e que a URL da API esteja configurada corretamente no app. Para dispositivos físicos, utilize o IP local do servidor em vez de `localhost`.

## Estrutura

- `app/`: telas do aplicativo
- `components/`: componentes reutilizáveis
- `services/`: chamadas de API
- `contexts/`: contextos React (por exemplo, fonte de dados)
- `constants/`: cores, temas, etc.
- `models/`: tipos utilizados nas interfaces
